# 受入ゲート計画

要件IDは `docs/REQUIREMENTS.md` を参照してください。この文書で決めるのは受入確認の順序と判定条件だけです。アーキテクチャや実装方式は決めず、完了時期も約束しません。
各ゲートは、対象の要件IDがすべて `PASS` または根拠付きの `N/A` になった時点で通過とします。証拠がなければ通過扱いにしません（X-06）。

- ホスト: Windows 11 x64。受入証拠には、ワークスペース内の隔離環境 `.venv`（CPython 3.12.15 x64）を使います。ホストの Python 3.10 は使いません。構築の記録は `output/environment-setup.log`、依存関係の固定は `requirements-lock.txt` にあります。

- コードベース：エンジン・CLI・GUIは実装済みで凍結しています。最終の一括テストは281 passed（`output/final-validation/`）です。
- 4つのタスク（01〜04）はすべて承認済みで、実施しました。状態は [FINAL_REPORT.md](FINAL_REPORT.md) と [REQUIREMENTS.md](REQUIREMENTS.md) を参照してください。

## 当初の確認事項と、その結果（2026-10-20）

1. **外部アクセス**：4タスクとも承認されました。取得したものは `input/`（ソースプロファイル、調査の原証拠、RAWサンプル）と `output/` に保存し、URL・ハッシュを記録しています。アプリは実行中にネットワークを使いません。
2. **RAW入力プロファイルからのLUT**：技術用LUTは「ICCデバイスRGB → sRGB」として、入力条件を明記して別に出力しました（`RAW_DEVICE`）。写真用ルックはsRGB → sRGBで、D70sだけを `_EXPERIMENTAL` として出力しました（L1-05、L1-07）。
3. **Pythonの扱い**：別々の成果物として扱いました。01の再生成スクリプトはPythonで動き、03の配布物は、スモークテストで `PATH` にPythonがない状態での動作を確認しました（クリーンなVMでは未確認のため、S3-13はPARTIAL）。
4. **インストーラーの方式**：Nuitka 2.7.12（standalone）とInno Setup 6.0.5（ユーザー単位、未署名）を使います。
5. **任意の項目**：65³、17格子、補間誤差のΔE00は実施しました。実機とのΔE00は参照データがないため測定できず、理由を記録しました（L1-11）。
6. **D200 ICCの33格子CLUT**：A2B0が33格子であることを実ファイルで確認しました（`profile_facts.json`）。
7. **ライセンス**：外部のカメラプロファイルは同梱しません。Fluentアイコン（MIT）は告知とともに同梱します。一般への再配布条件はクリアしておらず、法的な保証もしません（S3-15はPARTIAL）。
