# Claude Code の使い方（このプロジェクト用）

このリポジトリには Claude Code 用の設定が入っています。何が自動で動き、何を自分で頼むのかをまとめます。

## 最初に1回だけ

1. Claude Code をこのフォルダで起動する。
2. `/hooks` と打ち、フックが5つ（SessionStart、UserPromptSubmit、PreToolUse、PostToolUse、Stop）表示されることを確認する。
3. `py scripts/check.py` を自分で実行し、`GATE: PASS` が出ることを確認する。
   - 失敗したら、テストの依存が入っているか（`pip install -e .[gui,raw,test]`）を確認する。
   - `py -3.12` が見つからないと言われたら、`scripts/check_commands.txt` の `py -3.12` を自分の Python のコマンドに変える。
4. `CLAUDE.md` を読み、違っているところを直す（特に「決まっていること」）。

## 自動で動くもの（何もしなくてよい）

| いつ | 何が起きるか |
|---|---|
| Claude が作業を終えようとしたとき | ファイルが変わっていれば `scripts/check.py`（＝テスト）を実行。失敗なら Claude に結果を返して作業に戻す。最大3回。同じ失敗が2回続いたら、直すのをやめて STATE.md に書いて報告させる |
| Claude がファイルを編集しようとしたとき | `.env`、鍵ファイル、`.git/`、フック、`scripts/check.py` などは編集を止める（一覧は `.claude/protected_paths.txt`） |
| `git push` や `rm -rf` | 実行前に確認を求められる。`git push --force` は禁止 |

質問に答えただけのターンでは、テストは走りません。

## 自分で頼むもの

**不具合を直す**
```
/fix-bug DCP を読み込むと LookTable がないファイルでエラーになる
```
再現テスト → 最小の修正 → テスト、の順で進み、証拠つきで報告されます。

**新しい機能を作る**
```
/spec 書き出し時にファイル名の連番ルールを選べるようにしたい
```
質問に答えると `SPEC.md` ができます（コードは変わりません）。内容がよければ:
```
/clear
/task SPEC.md
```
契約（完了条件）を書いてから、計画 → 実装 → テスト → レビューまで進みます。

**作業を中断する・別の作業に移る**
```
/handoff
/clear
```
再開するときは「STATE.md を読んで続きから」と頼みます。

**レビューしてほしい**
```
reviewer サブエージェントで、今の差分を SPEC.md と突き合わせてレビューして
```
もっと厳しく確かめたいときは `verifier`、長いテスト出力を要約させたいときは `test-runner` を名前で指定します。

## うまくいかないとき

- **同じ訂正を2回しても直らない** → 3回目を言わずに `/clear` し、分かったことを書き足した依頼を出し直す。
- **テストがいつまでも通らず止まった** → 画面に「GATE: … 停止しました」と出ます。STATE.md と Claude の報告を読んで判断してください。
- **一時的にテストの自動実行を止めたい** → `.claude/gate.off` という空ファイルを置く（消せば戻る）。
- **完了判定にGUIテストも含めたい** → `scripts/check_commands.txt` のコメントに切り替え方があります（このファイルは Claude には編集させない設定なので、自分で直します）。
- **同じ注意を何度もしている** → `CLAUDE.md` の「2回以上直したこと」に1行足す。それでも守られなければ、テストや lint のルールにする。

## 注意

- `.gitignore` に `.claude/` が入っているので、`.claude/` 以下の設定（フック、スキル、サブエージェント）は git に入りません。このPCだけで使うならそのままで大丈夫です。別のPCでも使いたいなら、`.gitignore` の `.claude/` を次の4行に置き換えてください:
  ```
  .claude/state/
  .claude/settings.local.json
  .claude/gate.off
  CLAUDE.local.md
  ```
- 保護フックが止めるのは Claude の編集ツールだけです。秘密情報はリポジトリの外に置くのが確実です。
